# Empeno e Torção

Aplicação web estática para registro, cálculo e visualização de empeno e torção da via permanente em estacas de 10 m, 5 m e 2,5 m.

Os dados ficam armazenados localmente no navegador. O site não usa logotipo ou símbolos da Rumo; apenas sua paleta cromática pública como referência visual.

## Publicação

O workflow em `.github/workflows/pages.yml` publica automaticamente no GitHub Pages após um push para `master` ou `main`. Nas configurações do repositório, selecione **GitHub Actions** como fonte do Pages.
